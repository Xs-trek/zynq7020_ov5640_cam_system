# 第三方组件与许可证

| 组件 | 用途 | 许可证 |
| --- | --- | --- |
| cJSON | JSON 处理，本地内嵌 | MIT |
| ncnn | YOLOv6Lite-S 推理 | BSD-3-Clause、BSD-2-Clause、Zlib |
| OpenCV | LK 光流 | Apache-2.0 |
| libjpeg-turbo | MJPEG 编码 | BSD-3-Clause、IJG、Zlib |
| OpenSSL libcrypto | WebSocket SHA-1/Base64 | Apache-2.0 |
| 88x2bu | USB WiFi 内核模块 | GPL-2.0-only |
| Linux/Xilinx drivers | V4L2 与板级驱动 | GPL-2.0-only 及上游条款 |

根目录 MIT 许可证只覆盖项目原创内容，不重新许可第三方代码、模型或 Xilinx XSA
内容。recipe 中固定的源码提交和 `LIC_FILES_CHKSUM` 是构建版本依据。
